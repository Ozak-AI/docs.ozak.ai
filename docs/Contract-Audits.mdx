## Ozak AI Presale Contract - External Audits

### CertiK Security Audit

* Audit Completed: June 16, 2025
* Codebase: Private (Solidity, EVM Compatible)
* Assessment Methods: Manual Review and Static Analysis
* Ecosystem: EVM-Compatible, Presale Contract Audit
