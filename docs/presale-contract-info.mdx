**Chain**: Ethereum Mainnet (Chain ID: 1)

**Explorer**: [https://etherscan.io](https://etherscan.io)

All OZ transactions are immutable and publicly visible, ensuring provable allocation and referral rewards.

Allocation Rules Hard-Coded in the Contract

| Bucket               | Supply %            | Notes                                                       |
| -------------------- | ------------------- | ----------------------------------------------------------- |
| Presale              | 30% (= 3 B OZ)      | 10 % liquid at TGE, remainder vests linearly over 6 months. |

The contract enforces a hard cap: once 3B tokens are allocated, the buy functions revert.

**Key Functions (Solidity ABI)**

| Function         | Signature                  | Purpose                                               |
| ---------------- | -------------------------- | ----------------------------------------------------- |
| `buyTokensETH()` | `payable`                  | Swaps incoming ETH for OZ at the current phase price. |
| `buyTokens()`    | Requires prior `approve()` | Accepts USDT or USDC (ERC-20); same rate table.       |
