$OZ Presale Token Purchase Guidelines

* $OZ is **only** available through the official website at[ ozak.ai/presale](https://ozak.ai/presale). It is **not yet** listed on any DEX.
* OZ will be claimable right after the presale ends - once the Token Generation Event (TGE) happens, you can import the token and see it in any ERC-20 wallet of your choice.

### **Before You Start**

| **✅ Do**                                                                                     | **❌ Don’t**                                                      |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Use a **self-custody wallet** (MetaMask, Trust Wallet, or any ERC-20-compatible alternative) | Send from an exchange wallet (Binance, Coinbase, Kraken).        |
| Keep at least **$10–$15 in ETH** for gas.                                                    | Forget gas fees - your buy will fail if the wallet has 0 ETH.    |
| Double-check you are on the **Ethereum (ERC-20) network**.                                   | Switch networks after connecting - this breaks the presale dApp. |

MetaMask and Trust Wallet are the recommended options because they’re fully tested with the Ozak dApp, but any self-custody wallet that supports Ethereum Mainnet will work.
