# Token Unlocks

See every token unlocking schedule, allocation and supply figure before it reaches the market.

## What is on the page

- A **chart** of unlock magnitude by day, so the big dates stand out immediately
- A **calendar grid** with the total value unlocking each day
- **Month** and **Week** views, with month navigation and a date picker

Unlock detail also appears inside [Signals → Events](/eon/signals), including **supply impact**, vesting, recipient and time remaining.
